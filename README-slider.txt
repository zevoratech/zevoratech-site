zevoratech.in - home page slideshow

Files (same names and folders as your zevoratech-site repository):
  index.html            new slideshow at the top of the home page
  styles.css            slideshow + scroll-fade styles added at the end
  script.js             slideshow and scroll-fade code added
  assets/kngc-slide.jpg picture for the KNGC slide

How to publish (GitHub web upload, like the privacy policy):
  1. github.com/zevoratech/zevoratech-site -> Add file -> Upload files
  2. Drag index.html, styles.css, script.js (replace the old ones) and the assets folder's kngc-slide.jpg
  3. Commit changes; the site updates in a minute or two. Hard refresh (Ctrl+F5) to see it.

To change a slide later: edit the matching <article class="slide ..."> block in index.html.
